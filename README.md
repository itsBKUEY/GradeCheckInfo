# GradeCheck

GradeCheck is a Chrome extension that estimates a grade for work you have already submitted to Canvas or Gradescope, before your instructor grades it. Once it's graded, GradeCheck explains where each point went.

## How it works

1. Install GradeCheck from the Chrome Web Store.
2. Get a free Google Gemini API key at https://aistudio.google.com/apikey and paste it into the extension's settings page.
3. Open an assignment you've submitted. An estimate appears next to the assignment title. Click it for the full breakdown.

GradeCheck is read-only and has no servers of its own. Your key and your results stay in your browser.

If your school runs Canvas at its own address (for example canvas.school.edu), add that domain on the settings page.
